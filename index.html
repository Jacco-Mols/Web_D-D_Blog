Killian Valkhof

Aan het begin van deze minor en daarvoor had ik zelf nog geen goed idee waar je nou precies JavaScript, CSS of HTML voor moet gebruiken. Ik vond het heel lastig te zeggen wat de beste manier was om iets te doen in een specifieke taal. Daarom was de eerste Weekly Nerd van Killian Valkhof juist zo fijn. Hij had het erover hoe je HTML en CSS kan gebruiken in plaats van JavaScript, en dit gaf mij eigenlijk wel een heel concreet beeld wat ik nou precies kan doen met CSS.

Je kan dus bijvoorbeeld appearance: none; gebruiken in CSS om zelf een input element te gaan stylen. Ook ben ik in deze weekly nerd erachter gekomen wat de pseudo-elementen before en after zijn en dat deze niet werken zonder content: “”.

Het is ook interessant om te horen hoe je CSS kan toepassen voor een betere UX-design. Zo kan je bijvoorbeeld preferred reduced motion, no preference aanzetten, zodat mensen die dit in de settings hebben mogelijke animaties niet te hoeven zien. Verder vond ik dat Killian heel veel handige tips en trucjes had laten zien in CSS die ik niet op een andere manier had kunnen leren. Wat ik alleen wel jammer vond, is dat ik op dat moment in de minor heel graag meer van javaScript wou leren. En hier heeft Killian het niet heel veel over gehad, wat ik zelf wel jammer vond. Ook had Killian verteld over onderwerpen waar ik zelf al bekend mee was, zoals een hover state en hoe je dit kan toepassen in CSS of een details element in HTML.

Wat ik wel interessant vond, is om te horen dat Killian zijn eigen browser had gemaakt, genaamd PolyPane. En dit vond ik heel interessant om te horen en om te zien wat ik nou precies in deze branche zou kunnen worden.
